Formularios

Cada formulario pide solo lo necesario: el resto se completa solo con las llaves foráneas de la base de datos.

Vista de diseño. Estos formularios aún no están conectados a la base de datos jags_technology. Los códigos (S001, AC001, C001…) siguen el formato de las tablas.

Ir a un formulario:

Solicitud de servicioRegistro de clienteCotizaciónOrden de trabajoVentaGarantíaAsesor comercialTécnicoProveedorPlan corporativoAsignar proveedor

Los campos con * son obligatorios.

Para clientes

Solicitud de servicio Tabla: solicitud

Es lo que le pides a Jags Technology. Solo necesitamos tu documento y lo que necesitas.

Solo números (6 a 15 dígitos). Debe estar registrado.
Máximo 300 caracteres.
Se completa solo: id_solicitud (S001, S002…), estado (Pendiente), fecha_creacion (fecha y hora actual), id_proveedor (lo asigna el equipo).

Para clientes

Registro de cliente Tabla: cliente

Regístrate una sola vez. Con tu documento harás todas tus solicitudes.

Tipo de cliente *
Es tu identificador en el sistema: de 6 a 15 dígitos.
Obligatorio para clientes Natural.
Obligatorio para clientes Natural.
Obligatorio para clientes Corporativa.
Se completa solo: fecha_registro (fecha de hoy).

Equipo Jags · Asesor comercial

Cotización Tabla: cotizacion

La elabora un asesor comercial a partir de una solicitud.

Código con formato S001. El cliente se toma de la solicitud.
Código con formato AC001.
Solo clientes corporativos (PC001 Avanzado, PC002 Premium). Déjalo vacío si el cliente es Natural.
Máximo 300 caracteres.
Se completa solo: id_cotizacion (C001, C002…), estado (Emitida), fecha_emision (fecha de hoy).

Equipo Jags · Coordinación

Orden de trabajo Tabla: orden_trabajo

Se crea cuando una cotización es aprobada. Menciona al cliente, al técnico y la descripción.

Código con formato C001. El cliente se toma de la cotización.
Código con formato T001.
Máximo 300 caracteres.
Se completa solo: id_orden (OT001, OT002…), id_cliente (del cliente de la cotización), estado (Programada).

Equipo Jags · Ventas

Venta Tabla: venta

Se registra al finalizar el trabajo.

Código con formato C001.
Máximo 300 caracteres.
Se completa solo: id_venta (V001, V002…).

Equipo Jags · Postventa

Garantía Tabla: garantia

Cada venta tiene como máximo una garantía.

Código con formato V001. El asesor y el técnico se toman de la venta.
Máximo 150 caracteres.
Se completa solo: id_garantia (G001, G002…), id_asesor (del asesor de la cotización), id_tecnico (del técnico de la orden), fecha_vencimiento (fecha de finalización + meses).

Equipo Jags · Administración

Asesor comercial Tabla: asesor_comercial

Empleados del área de ventas.

Se completa solo: id_asesor (AC001, AC002…), activo (Sí).

Equipo Jags · Administración

Técnico Tabla: tecnico

Empleados de soporte.

Se completa solo: id_tecnico (T001, T002…), activo (Sí).

Equipo Jags · Compras

Proveedor Tabla: proveedor

Empresas que suministran equipos o materiales.

Se completa solo: id_proveedor (PV001, PV002…), activo (Sí).

Equipo Jags · Administración

Plan corporativo Tabla: plan_corporativo

Solo existen dos planes: Avanzado y Premium. Se usan únicamente con clientes corporativos.

Se completa solo: id_plan (PC001, PC002), activo (Sí).

Equipo Jags · Compras

Asignar proveedor a una solicitud Tabla: solicitud (actualiza id_proveedor)

Cuando el trabajo requiere equipos o materiales, se asigna un proveedor a la solicitud.

Código con formato S001.
Código con formato PV001. Un solo proveedor por solicitud.
Se completa solo: id_proveedor (se guarda en la solicitud).
